# Security reporting

For accidental disclosure of private material, or a security problem in a release asset,
email **research@macbrainslabs.org** with the affected revision, environment,
reproduction steps and likely impact. Do not post exploit details, tokens or personal
data in a public issue.

This is an independent research project. No formal supported-release lifecycle or
response SLA is promised, and this policy is not a claim of an external audit.

Measurement questions and documentation corrections may use GitHub issues.
